# 02 — Database Tables

## Goal

Every MVP table exists as a Flyway migration with a matching JPA entity and repository, and Hibernate's `validate` mode confirms they agree.

## In Scope

- Migrations, entities, enums and repositories for: `users`, `activities`, `test_cases`, `sdi_configs`, `coding_sessions`, `telemetry_events`, `reflections`.

## Out of Scope

- `alerts` and `debugging_prompts` (should/could specs create them).
- Services, controllers and business rules.
- Seed data.

## Requirements

- **R1** IDs are `bigint generated by default as identity` (portable to H2). Timestamps are `timestamp with time zone`. Enumerations are `varchar` with a `CHECK` constraint, not database enum types.
- **R2** `V1__users.sql`
  - `users(id, name varchar(100) not null, email varchar(254) not null unique, password_hash varchar(100) not null, role varchar(16) not null check (role in ('STUDENT','INSTRUCTOR')), consent_accepted_at timestamptz null, created_at timestamptz not null)`
  - Emails are stored lower-case (enforced in code, spec 05).
- **R3** `V2__activities.sql`
  - `activities(id, instructor_id bigint not null references users(id), title varchar(120) not null, problem_statement text not null, starter_code text not null default '', status varchar(16) not null check (status in ('DRAFT','PUBLISHED','ARCHIVED')), created_at timestamptz not null, updated_at timestamptz not null)`; index on `instructor_id`; index on `status`.
  - `test_cases(id, activity_id bigint not null references activities(id) on delete cascade, position int not null, input text not null default '', expected_output text not null, is_hidden boolean not null default false)`; unique `(activity_id, position)`.
  - `sdi_configs(id, activity_id bigint not null unique references activities(id) on delete cascade, threshold int not null check (threshold between 0 and 100), cooldown_seconds int not null check (cooldown_seconds >= 0), window_minutes int not null check (window_minutes >= 1))`.
- **R4** `V3__sessions_and_telemetry.sql`
  - `coding_sessions(id, student_id bigint not null references users(id), activity_id bigint not null references activities(id), started_at timestamptz not null, ended_at timestamptz null, peak_sdi int null check (peak_sdi between 0 and 100), runner_locked boolean not null default false, sdi_at_lock int null check (sdi_at_lock between 0 and 100), cooldown_ends_at timestamptz null)`; index `(student_id, activity_id, started_at)`.
  - `telemetry_events(id, session_id bigint not null references coding_sessions(id), client_event_id uuid not null, type varchar(8) not null check (type in ('EDIT','RUN','ERROR')), occurred_at timestamptz not null, chars_added int null, chars_removed int null, passed_count int null, total_count int null, error_signature varchar(200) null, sdi_value int null check (sdi_value between 0 and 100))`; unique `(session_id, client_event_id)`; index `(session_id, occurred_at)`.
  - `reflections(id, session_id bigint not null references coding_sessions(id), hypothesis text not null, planned_fix text not null, sdi_at_trigger int not null check (sdi_at_trigger between 0 and 100), submitted_at timestamptz not null)`; index on `session_id`.
- **R5** One entity per table in its feature package (`user.User`, `activity.Activity`, `activity.TestCase`, `activity.SdiConfig`, `session.CodingSession`, `telemetry.TelemetryEvent`, `reflection.Reflection`). Enums `Role`, `ActivityStatus`, `EventType` stored with `@Enumerated(EnumType.STRING)`. Timestamps are `Instant`.
- **R6** Relationships are mapped as plain ID columns or `@ManyToOne(fetch = LAZY)`; no bidirectional collections except `Activity` → `TestCase` (ordered by `position`).
- **R7** Repositories extend `JpaRepository`. Add only these query methods now: `UserRepository.findByEmail(String)`, `UserRepository.existsByEmail(String)`, `ActivityRepository.findByInstructorIdOrderByUpdatedAtDesc(Long)`, `ActivityRepository.findByStatusOrderByTitleAsc(ActivityStatus)`, `SdiConfigRepository.findByActivityId(Long)`. Later specs add what they need.

## Parts

1. `V1` + `User` + `UserRepository`.
2. `V2` + `Activity`, `TestCase`, `SdiConfig` + repositories.
3. `V3` + `CodingSession`, `TelemetryEvent`, `Reflection` + repositories.

Each part: `./mvnw test` passes (Hibernate `validate` runs against the migrated H2 schema).

## Acceptance Criteria

- [ ] All three migrations run on H2 (tests) and on a local PostgreSQL (manual start-up).
- [ ] Hibernate schema validation passes; no `ddl-auto` other than `validate` is used.
- [ ] Inserting a duplicate email fails; inserting `sdi_configs.threshold = 101` fails; a duplicate `(session_id, client_event_id)` fails.
- [ ] Deleting an activity deletes its test cases and SDI config.
- [ ] No table outside R2–R4 exists.

## Tests

- `UserRepositoryTests`: save and `findByEmail`; duplicate email throws.
- `ActivityRepositoryTests`: save activity with two test cases, reload ordered by position; cascade delete removes test cases and config.
- `TelemetryEventRepositoryTests`: duplicate `(session_id, client_event_id)` throws; `sdi_value = 150` throws.
